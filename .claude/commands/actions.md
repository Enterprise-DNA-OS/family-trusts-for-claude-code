# actions

Follow-up actions, open by default (--all includes closed ones).

Run `node scripts/trusts.mjs actions [--all]`. Add `--json` when you need every field. Resolve the trust, person, resolution or request by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
