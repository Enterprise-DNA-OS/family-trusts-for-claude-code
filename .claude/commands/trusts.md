# trusts

List the trusts, active by default (--all includes wound-up ones), optionally for one family.

Run `node scripts/trusts.mjs trusts [--family=<family>] [--all]`. Add `--json` when you need every field. Resolve the trust, person, resolution or request by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
