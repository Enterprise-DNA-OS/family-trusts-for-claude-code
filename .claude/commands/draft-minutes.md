# draft-minutes

Draft the minutes of the annual trustee review: deed, people, property, loans and the matters to decide, to drafts/.

Run `node scripts/trusts.mjs draft-minutes <trust>`. Add `--json` when you need every field. Resolve the trust, person, resolution or request by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
