# insights

Answer the ten questions the practice software cannot: holdings by family, settlor loans and gifting, who received what, missed deadlines by manager, resolution timing, trustees of several trusts, beneficiaries never told, minors' allocations, stale valuations and trusts vesting.

Run `node scripts/trusts.mjs insights`. Add `--json` when you need every field. Resolve the trust, person, resolution or request by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Present each question with its table. Point out the one finding that needs a decision.
