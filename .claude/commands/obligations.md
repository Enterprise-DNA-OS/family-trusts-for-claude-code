# obligations

Every dated obligation on every trust, or one trust, with the rule that sets it. Open and overdue by default; --all includes the done ones.

Run `node scripts/trusts.mjs obligations [<trust>] [--all]`. Add `--json` when you need every field. Resolve the trust, person, resolution or request by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Group by trust when there are more than ten lines.
