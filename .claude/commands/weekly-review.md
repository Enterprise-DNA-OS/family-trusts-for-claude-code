# weekly-review

Write the Monday review to drafts/: what needs a person, the year end for every trust, and beneficiary requests waiting.

Run `node scripts/trusts.mjs weekly-review`. Add `--json` when you need every field. Resolve the trust, person, resolution or request by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Then summarise it in five lines: the worst legal breach, the year end, requests, documents, the one decision needed.
