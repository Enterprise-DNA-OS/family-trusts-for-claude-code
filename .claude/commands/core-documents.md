# core-documents

The core documents a trustee keeps (Trusts Act 2019 s 45), trust by trust: deed, variations, last year's accounts, decisions, appointment records, memorandum of wishes, asset records.

Run `node scripts/trusts.mjs core-documents [<trust>]`. Add `--json` when you need every field. Resolve the trust, person, resolution or request by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

List what is missing first and who to ask for it.
