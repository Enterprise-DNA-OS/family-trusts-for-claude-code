# register

The register of people: every current trustee, settlor, appointor, protector and beneficiary (--all includes past roles), for one trust or all.

Run `node scripts/trusts.mjs register [<trust>] [--all]`. Add `--json` when you need every field. Resolve the trust, person, resolution or request by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
