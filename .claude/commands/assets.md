# assets

The trust property: what each trust holds, cost, value and when it was valued (--all includes disposals).

Run `node scripts/trusts.mjs assets [<trust>] [--all]`. Add `--json` when you need every field. Resolve the trust, person, resolution or request by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
