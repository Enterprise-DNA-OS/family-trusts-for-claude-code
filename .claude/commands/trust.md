# trust

One trust in full: details, people, open obligations, assets, loans and recent resolutions.

Run `node scripts/trusts.mjs trust <trust>`. Add `--json` when you need every field. Resolve the trust, person, resolution or request by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Read this before drafting anything about the trust.
